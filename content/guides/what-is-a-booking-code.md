A booking code is a short string of letters and numbers that stores a complete betslip, so anyone can load the same selections on the same bookmaker without picking them one by one. If you have ever wondered what a booking code is in betting, think of it as a shareable shortcut: a friend or tipster builds a slip, generates a code, and you type that code into your own account to recreate the slip in seconds. The code saves the selections only, never the stake or the money.

## What is a booking code in betting?

When you add selections to a betslip, the bookmaker can save that slip on its servers and give it a reference. That reference is the booking code. It records which events you picked, which markets (for example 1X2 or over 2.5 goals) and which outcomes. When someone enters the code, the bookmaker looks up the saved slip and drops the same selections into their betslip at the *current* odds.

A few important points follow from this:

- **The code belongs to one bookmaker.** A SportyBet code only works on SportyBet, and a Bet9ja code only works on Bet9ja. To move a slip between bookmakers you need a conversion tool such as our [booking code converter](/booking-code-converter).
- **Odds are not frozen.** If the odds have moved since the code was created, you get the new price.
- **No money changes hands.** Loading a code does not place a bet. You still choose your stake and confirm the bet yourself.

## What different bookmakers call it

The idea is the same everywhere, but the name varies. In Nigeria and Ghana the term "booking code" is standard, and on Bet9ja you will also see "booking number". Other bookmakers use labels such as "share code", "share bet" or "bet code". Here is a quick overview of how the feature tends to appear at popular African bookmakers:

Features and labels change from time to time, so treat this as a guide rather than a rulebook.

## How to create a booking code

The steps are broadly similar on every bookmaker that supports booking codes:

1. Open the sportsbook on the website or app. On many bookmakers you do not even need to be logged in.
2. Add your selections to the betslip, for example three home wins and an over 2.5 goals pick.
3. Look for a button labelled "Book bet", "Share", "Get booking code" or similar, usually at the bottom of the betslip.
4. The bookmaker shows a code, often with a link and buttons to copy it or share it on WhatsApp, Telegram or social media.
5. Copy the code and send it to whoever needs it.

## How to load a booking code

Loading a code is just as quick:

1. Go to the sportsbook home page or open the betslip.
2. Find the field labelled "Booking code", "Load code" or "Enter code".
3. Type or paste the code and tap "Load".
4. Check the selections that appear. Compare them against what you expected, especially the markets and the odds.
5. Enter your stake and place the bet if you are happy with it.

If the code returns an error, it may be mistyped, it may belong to a different bookmaker, or it may have expired.

## Why booking codes expire

A booking code is tied to real fixtures, so it cannot live forever. The most common reasons a code stops working, fully or partly, are:

- **Matches have started.** Once a selection's event kicks off, the pre-match market closes. Depending on the bookmaker, the code may load without that selection, load it at live odds, or fail entirely.
- **Markets have been suspended or removed.** If a bookmaker pulls a market, the selection can no longer load.
- **Time limits.** Many bookmakers delete saved slips after a set period or once all the events have finished.
- **Events have been postponed or cancelled.** A postponed match may vanish from the sportsbook.

The practical lesson is simple: load codes as early as you can, and always check the slip before you stake. If one or two selections drop out, the total odds of the rest change too.

## Why tipsters share booking codes

Booking codes have become central to betting culture in Nigeria, Ghana and Kenya, and increasingly in South Africa. Tipsters post them on Telegram, WhatsApp, X and TikTok because:

- **They save time.** Copying a 15-leg accumulator by hand is slow and error-prone. A code does it instantly.
- **They reduce mistakes.** Picking the wrong market (say, over 1.5 instead of over 2.5) is easy when typing selections manually.
- **They build a following.** A tipster can post one code and thousands of followers can load it.

Be cautious, though. A booking code is just a list of picks; it says nothing about whether those picks are good. Many tipsters post huge accumulators with very long odds, and the chance of all legs winning is tiny. Anyone *selling* "sure" or "fixed" codes is almost certainly running a scam. ## A quick worked example

Imagine a tipster shares a four-leg code with total odds of 8.40. You load it on the same bookmaker an hour later. One match has kicked off and drops out, and the odds on another have shortened from 1.80 to 1.65. The new slip has three selections and total odds of about 4.30. A ₦1,000 stake now returns roughly ₦4,300 if all three win, rather than the ₦8,400 you might have expected. This is why reviewing the slip before staking matters every time. ## FAQ

### Is a booking code the same as a bet ID?

No. A booking code stores selections so that anyone can load them before placing a bet. A bet ID or ticket ID refers to a bet that has already been placed with a stake. Some bookmakers let you generate a shareable code from a placed bet, but the two references serve different purposes.

### Can I use a SportyBet booking code on Bet9ja?

Not directly. Booking codes only work on the bookmaker that created them. To use a SportyBet slip on Bet9ja, Betway or another bookmaker, you need to recreate the selections there, either by hand or with a tool such as the OddsBridge booking code converter.

### Does loading a booking code place the bet automatically?

No. Loading a code only fills your betslip with the selections. You still need to enter a stake, review the odds and confirm the bet yourself. Nothing is charged until you place the bet.

### Why do the odds on a booking code change?

The code stores selections, not prices. When you load it, the bookmaker shows its current odds, which may have moved since the code was created because of team news, betting activity or kickoff approaching. Always check the total odds before staking.

### How long does a booking code last?

It depends on the bookmaker, but most codes stop working fully once the matches on the slip start or finish, and many are deleted after a set period. Load codes well before kickoff for the best chance of every selection being available.
